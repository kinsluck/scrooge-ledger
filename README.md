# 史高治账本 · Scrooge Ledger

单文件、零依赖、纯离线的记账应用。名字借自唐老鸭的叔叔 —— **史高治·麦克达克**，那只在金币堆里游泳、把每一分钱都记得清清楚楚的苏格兰鸭子。

☝️ **每一分钱，都要算清楚。**

整个应用就是一个 HTML 文件（约 230 KB），没有任何外部依赖、没有后端、不联网也能跑。数据存在你浏览器的 `localStorage` 里。

**在线直接用：<https://kinsluck.github.io/scrooge-ledger/>**

## 功能

**记账**
- 支出 / 收入 / 转账三种记法，支持自定义分类、账户、标签
- 明细按月份分组，可搜索备注、分类、金额
- 固定支出（周期性账单）自动入账

**导入导出**
- 导入记账 App 导出的 `xlsx` / `csv` 账单（内置解析器，不依赖 SheetJS）
  - 表头按同义词模糊匹配，常见列名都能认
  - 也支持拖拽文件到页面
- 导出 **带图表的 Excel 报告**（A4 一页：KPI + 4 张图 + 明细表 + 数据表）
- 导出 JSON 备份 / CSV / 一键复制备份

**图表与洞察**
- 日 / 周 / 月三种粒度 × 支出 / 收入 / 结余
- 分类占比环形图（带引导线图例）、分类排行、储蓄率曲线
- 支出日历热力图、星期 × 时段热力图、分类堆叠面积、单笔 Top 5
- 预算执行进度与 20% 储蓄率健康线

**主题**
- 深色 / 浅色两套，跟随切换即时生效

## 直接使用

下载 `index.html`，双击用浏览器打开即可。建议加到手机主屏幕，当作本地 App 用。

## 本地构建

应用由 `src/` 下的片段拼成单文件：

```
src/
├── build.py           拼接脚本
└── parts/
    ├── 01-head.html
    ├── 02-style.css
    ├── 03-body.html
    ├── 04-core.js      工具 / 存储 / 派生计算
    ├── 05-charts.js    SVG 图表引擎
    ├── 06-import.js    xlsx / csv 解析
    ├── 07-views.js     视图渲染
    ├── 08-events.js    交互
    └── 09-xlsx.js      带图表的 xlsx 导出
```

```bash
python src/build.py                                  # 输出 ../史高治账本.html
SHIGUANG_OUT=index.html python src/build.py          # 输出到当前目录的 index.html
```

## 数据说明

- 所有数据只存在当前浏览器，**不会上传到任何服务器**
- 清除浏览器数据会一并清掉账本，请定期用「导出 JSON 备份」
- 存储 key 仍是 `shiguang-ledger-v1`（改名前就在用这个 key，改名不迁移数据）
